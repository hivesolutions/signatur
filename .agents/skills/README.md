# Agent Skills

These provide instructions for common tasks:

| Skill             | Description                                                                                                                                                                |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `match-f3s-fonts` | Tune and verify the TTF fonts so the viewport matches the Gravostyle engraving of their F3S counterparts, proven with the viewport against gravo-pilot dry run screenshots |

Each skill has a `SKILL.md` with instructions and supporting files like `reference.md`, `examples.md` and `scripts/`.
